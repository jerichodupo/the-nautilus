# Nautilus Coastal Residences

Build a polished, highly-converting multi-page real estate website for THE NAUTILUS at CaSoBē in Calatagan, Batangas, a luxury beachfront condominium/property ownership project.

IMPORTANT GOAL:
This replaces the previous Systeme.io funnel website. Recreate the website structure and conversion strategy we established, but execute it as a premium modern real-estate website, not a generic resort website.

BRAND:
- Primary brand color: #248099 (Deep Sea Teal)
- Supporting colors: #FFFFFF, #E3DAC9 Calatagan Sand, #705335 Tropical Timber, #E07A5F Sunset Coral, #2C3539 Gunmetal Gray.
- Heading font: Raleway.
- Choose a fitting body font that pairs elegantly with Raleway and feels premium, warm, highly readable, and contemporary. Prefer a clean humanist/sans-serif such as Lato or similar if appropriate.
- Visual direction: minimalist tropical luxury, architectural, organic, sophisticated, warm, serene, exclusive, aspirational.
- Avoid cheesy nautical graphics such as anchors, ropes, ship wheels, etc.
- The visual language should feel like a luxury property showroom / architectural real-estate brand.
- Use generous whitespace, strong typography, high-quality imagery, subtle motion, elegant cards, restrained shadows, and premium spacing.
- Mobile responsive and accessibility-conscious.

CONVERSION STRATEGY:
Visitor journey: Desire → Trust → Information → Investment → Action.
The website should answer: “Why should I want to own a place here?” rather than merely “Why should I stay here?”
Primary CTA throughout: INQUIRE / REQUEST PROJECT DETAILS.
Secondary CTAs: EXPLORE OWNERSHIP, VIEW RESIDENCES, EXPLORE INVESTMENT.
Use clear repeated CTAs without becoming pushy.
Capture leads with an inquiry form.

SITE STRUCTURE / ROUTES:
1. Home
2. Residences
3. The Experience
4. Investment
5. Location & CaSoBē
6. Inquire

GLOBAL HEADER:
- Transparent/overlay header on the Home hero image.
- Logo at top-left (use the supplied The Nautilus logo if available; otherwise create a tasteful text-logo placeholder that can easily be replaced).
- Navigation: HOME, RESIDENCES, EXPERIENCE, INVESTMENT, LOCATION
- Strong INQUIRE CTA.
- On interior pages, use a solid/light header appropriate to the hero.
- Sticky header behavior with subtle background change on scroll.
- Mobile hamburger menu.
- Keep navigation elegant and uncluttered.

HOME PAGE SECTIONS:
1. Full-viewport hero with luxury beachfront/architectural image.
   Headline: “WHERE THE HORIZON BECOMES HOME.”
   Subheadline: “The Nautilus at CaSoBē, Calatagan, Batangas. Luxury beachfront residences for coastal living, personal escape, and ownership.”
   CTAs: Explore Ownership / View Residences.
2. “A PLACE TO LIVE. A PLACE TO ESCAPE. A PLACE TO OWN.”
   Three value cards: Architectural Icon, Beachfront Living, Ownership Opportunity.
3. “MORE THAN A BEACHFRONT ESCAPE.”
   Explain private coastal residences, personal use, and optional Landco Lifestyle Ventures rental/leaseback participation subject to applicable terms. Do not promise returns.
   3-step visual: OWN → ENJOY → ENROLL.
4. Early lead capture section:
   “COULD THE NAUTILUS BE YOUR NEXT COASTAL ADDRESS?”
   Fields: First Name, Last Name, Email, Mobile Number, Interested Unit (Studio, 1 Bedroom, 1 Bedroom Loft, 2 Bedroom, 2 Bedroom Loft, Loft, Not sure), Primary Interest (Personal use, Investment, Both, Still exploring), Message.
   CTA: REQUEST PROJECT DETAILS.
5. “YOUR ESCAPE, WITHIN REACH.”
   CaSoBē / Calatagan location story.
6. “AN ARCHITECTURAL ICON BY THE SEA.”
   Architecture story inspired by maritime exploration and sanctuary concept.
7. “FIND YOUR PLACE BY THE SEA.”
   Residence type cards with sizes:
   Studio — 38.1–39.0 sqm
   1 Bedroom — 63.1–92.2 sqm
   1 Bedroom Loft — 65.0–79.9 sqm
   2 Bedroom — 76.4–96.5 sqm
   2 Bedroom Loft — 123.4–124.6 sqm
   Loft — 138.2–182.7 sqm
   Mention 176 residences; availability/pricing to be confirmed.
8. “MORE THAN A RESIDENCE.”
   Amenities: Beachfront, Infinity Pool, Fitness & Yoga, Spa & Sauna, Restobar, Gameroom, Speakeasy, Lobby Lounge, Retail, Conference Room.
9. “LET YOUR RESIDENCE WORK FOR YOU.”
   Explain optional rental/leaseback concept carefully; use “subject to program terms” and no guaranteed income language.
10. “BACKED BY LANDCO.”
    Developer trust section: Landco Pacific Corporation, 30+ years of experience.
11. Owner benefits section: Landco Privilege Program/Club benefits, subject to terms.
12. FAQ accordion covering unit types, sizes, beachfront/sea views, rental/leaseback, management, amenities, location, pricing and inquiry.
13. Strong final CTA: “YOUR PLACE BY THE SEA.” with INQUIRE NOW.

INQUIRE PAGE:
- Premium inquiry page.

UX REQUIREMENTS:
- Above-the-fold CTA immediately visible.
- Sticky/visible inquiry CTA.
- Clear visual hierarchy.
- Scannable sections.
- Use progressive disclosure where useful.
- Avoid giant walls of text.
- Include subtle scroll reveal animations but respect prefers-reduced-motion.
- Buttons should have strong contrast and obvious hover/focus states.
- Use real estate conversion patterns: trust signals, lifestyle visualization, product clarity, investment explanation, repeated inquiry opportunities.
- Add polished footer with navigation, contact, developer information, and legal/disclaimer links.
- Use tasteful image placeholders/remote imagery where appropriate, but structure components so project-specific images can be swapped easily.
- Do not use fake testimonials, fake awards, fake statistics, fake reviews, fake urgency, or fabricated financial claims.
- Build reusable components for Header, Footer, CTA sections, PropertyCard, AmenityCard, InquiryForm, FAQ, SectionHeading, and responsive navigation.
- Make the result feel production-ready, not like a template.

TECHNICAL:
- Use Lovable's standard React/TypeScript/Tailwind stack.
- Use semantic HTML and responsive layouts.
- Set up routes for all six pages.
- Ensure navigation works between routes.
- Keep content/data centralized where practical for easy editing.
- Use #248099 as the primary design token throughout the system.
- Make the design system consistent across every page.
